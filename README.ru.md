# UniDeskBrowser

UniDeskBrowser — клиент удалённого рабочего стола для Linux на GTK 3, форк
[Remmina](https://gitlab.com/Remmina/Remmina) 1.4.43: все подключения открываются вкладками
в окнах, как в браузере.

[English version](README.md)

## Возможности

* **Протоколы:** RDP (FreeRDP 3), SSH, SFTP и Telnet.
* **Окна и вкладки, как в браузере:** несколько окон, в каждом свои вкладки. Вкладки окна —
  это сессия; сессии сохраняются при закрытии окна и при выходе, а при следующем запуске
  программа предлагает продолжить с того же места. Вкладки перетаскиваются между окнами или
  в новое окно. Каждое окно получает свой цвет, чтобы похожие окна не путались.
* **Домашняя вкладка:** слева список подключений, справа «История»: часто используемые
  подключения и сессии закрытых окон по дням.
* **SFTP:** двухпанельный файловый менеджер с клавишами Total Commander (F3 просмотр, F4 правка,
  F5 копирование, F6 перемещение, F7 каталог, F8 удаление…), операции в фоне, перетаскивание
  в другие файловые менеджеры и из них.
* **SSH ↔ SFTP:** меню вкладки открывает SFTP из вкладки SSH и терминал из вкладки SFTP —
  к тому же серверу, с теми же реквизитами.
* **Учётные данные:** профили — в одной базе, пароли — в зашифрованном хранилище (с главным
  паролем по желанию) или в системном хранилище. Профили Remmina импортируются при первом
  запуске.
* Тёмная тема; интерфейс на русском и английском; масштаб окна под XWayland подбирается сам.

## Отличия от Remmina

* Идентификатор приложения `uz.core.Unidesk`, исполняемый файл `unidesk`, плагины
  `unidesk-plugin-*`.
* Убраны модули VNC, SPICE, X2Go, EXEC, WWW и Python, онлайн-сервисы, режим киоска и Avahi;
  добавлен протокол Telnet.
* Каталоги пользователя: настройки — `~/.config/unidesk/`, данные и база подключений —
  `~/.local/share/unidesk/`, кэш — `~/.cache/unidesk/`. Каталоги Remmina только читаются,
  один раз, для импорта профилей.

## Сборка

Проект собирается CMake. Зависимости сборки и их версии (GTK 3, FreeRDP 3, libssh, VTE,
libsodium, libsecret, FUSE 3…) перечислены в
[`packaging/appimage/Dockerfile`](packaging/appimage/Dockerfile).

Переносимый AppImage (glibc 2.35 и новее) собирается в Docker:

```bash
bash packaging/appimage/build-image.sh    # один раз: образ сборки
bash packaging/appimage/build.sh          # AppImage — в ../unidesk-build/out/
```

Проверки и параметры сборки описаны в [`packaging/appimage/README.md`](packaging/appimage/README.md),
изменения версий — в [`RELEASES.md`](RELEASES.md).
