# UniDeskBrowser — журнал изменений

UniDeskBrowser — клиент удалённого доступа (RDP, SSH, SFTP, Telnet) для Linux, форк Remmina. Сборка — AppImage.

## 2.0 — в разработке

### Окна и сессии, как в браузере

- Несколько окон, в каждом свои вкладки; набор вкладок окна — сессия. Новое окно — Meta+N или кнопка «Новое окно» рядом с меню ☰; Meta+T — новая вкладка, Meta+W — закрыть вкладку, Meta+Shift+T — вернуть закрытую.
- Сессии сохраняются при закрытии окна и при выходе (`~/.config/unidesk/sessions.db`, атомарная запись, без паролей). При следующем запуске — «Продолжить с того же места»: окна возвращаются на свои места со своими вкладками; сразу подключается активная вкладка, остальные — при переходе на них.
- Вкладки перетаскиваются между окнами; вкладка, брошенная мимо окон, открывается в новом окне. Окно без вкладок закрывается, если открыты другие.
- Цвет окна: палитра из 9 цветов отмечает вкладки и заголовок окна; каждое новое окно по очереди получает следующий цвет.
- Сессии можно переименовать и сохранить (☰ → «Переименовать сессию…», меню вкладки).
- При захвате клавиатуры (правый Ctrl) все сочетания, в том числе Meta, уходят в удалённую сессию.

### Домашняя вкладка

- Слева список подключений, справа «История»: часто используемые подключения и сессии закрытых окон по дням. Удаление и очистка — без вопроса, с «Отменить» (и Ctrl+Z). Разделитель запоминается; в узком окне «История» открывается кнопкой во всплывающей панели.

### SSH и SFTP

- В меню вкладки SSH — «Открыть SFTP», в меню вкладки SFTP — «Открыть терминал SSH»: тот же сервер с теми же реквизитами (пароль, введённый при входе, передаётся только в памяти), новая вкладка — рядом с исходной; терминал открывается в папке удалённой панели.

### Экран

- В сеансе Wayland программа сама подбирает масштаб: если `GDK_SCALE` из окружения больше, чем нужно мониторам, он понижается (дробный масштаб — через размер шрифта). Сессия не возвращает окно меньше 600×400.

## 1.0 — 16.10.2026

Первый выпуск. До него программа называлась Unidesk.

### Имя и установка

- Программа называется UniDeskBrowser, идентификатор приложения — `uz.core.Unidesk` (ярлык, значки, значок трея). Файл сборки — `UniDeskBrowser-1.0-x86_64.AppImage`.
- Подключения, настройки, сохранённые пароли и известные хосты SSH остаются на прежнем месте (`~/.local/share/unidesk`, `~/.config/unidesk`, системное хранилище паролей): после обновления с Unidesk всё на месте, переносить ничего не нужно.
- Версия видна в «О программе» и в `--version`.

### Окно

- Одно окно со вкладками: первая вкладка с домиком — список подключений, дальше вкладки подключений и вкладка «+» для нового подключения; вкладки в строке заголовка.
- Meta+W закрывает текущую вкладку (и в удалённой сессии). F10 и другие функциональные клавиши уходят в сессию.
- Значок в трее (в Plasma тоже).
- Тёмная тема (палитра Breeze Dark); интерфейс на русском и английском, русский по умолчанию (Параметры → Язык интерфейса).

### RDP

- Качество «Лучшее» по умолчанию (ClearType, темы, обои); NTLM работает на любых системах (в сборку включён провайдер OpenSSL legacy).
- Буфер обмена с файлами в обе стороны: файлы, скопированные в Windows, вставляются в файловых менеджерах Linux, и наоборот.
- Выход с открытыми RDP-вкладками больше не завершается аварийно и не оставляет точек монтирования буфера.

### SSH и Telnet

- Встроенный протокол Telnet.

### SFTP

- Две панели как в Total Commander: слева этот компьютер, справа сервер; обе открываются в «/». Над панелями — «Локальный компьютер» и «SFTP: адрес сервера», свободное место; под панелями — итоги.
- Клавиши TC: F1 перечитать, F2 переименовать, F3 просмотр, F4 правка, F5 копировать, F6 переместить, F7 каталог, F8 удалить, Alt+A атрибуты (с пресетом 7777), Tab, Insert/Пробел, Num+ / Num- / Num*, Ctrl+A, Ctrl+F3…F6, Ctrl+H, быстрый переход набором букв.
- Копирование и перемещение в обе стороны с окном хода (пауза, в фоне, отмена), окном конфликта (заменить, пропустить, более старые, переименовать, докачать) и окном ошибки.
- F3 / F4 открывают файл программой по умолчанию или в редакторе (Параметры → Редактор SFTP); файл сервера скачивается во временную папку, после правки при сохранении предлагается загрузить его обратно.
- Перетаскивание: между панелями, из файловых менеджеров в любую панель, из обеих панелей наружу (файлы сервера Dolphin, Nautilus и другие программы копируют сами).

### Хранение данных

- Подключения в одной базе, пароли — в зашифрованном хранилище (главный пароль в Параметрах) или в системном хранилище; профили Remmina импортируются при первом запуске.

### Известные ограничения

- Перетаскивание между Dolphin и UniDeskBrowser на Plasma (Wayland) проверено только в X11; на Plasma его нужно проверить вручную.
- Несколько окон и сессии — в выпуске 2.0.
